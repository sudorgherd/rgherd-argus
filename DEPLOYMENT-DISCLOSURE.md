# Deployment Disclosure

ARGUS is licensed under the GNU Affero General Public License v3.0 or later.

ARGUS is intended to be self-hostable community infrastructure. Public or network-accessible deployments must respect the license terms.

## Modified network deployments

If you modify ARGUS and run the modified version for users over a network, those users must be offered access to the corresponding modified source code as required by the AGPL.

A practical deployment notice should include a visible source link, such as:

Source code for this ARGUS deployment is available at:
https://example.org/source

or:

This deployment runs a modified version of ARGUS.
Corresponding source code:
https://example.org/source

## What should be disclosed

The corresponding source should include the modified application code needed to build, inspect, and run the modified ARGUS software.

## What should not be disclosed

Do not publish secrets, private keys, tokens, passwords, database dumps, private user data, operational logs, private deployment credentials, or sensitive live-instance configuration.

License compliance does not require exposing private operational data.
