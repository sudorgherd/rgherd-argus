# ARGUS

ARGUS is an operator interface for dispatcher-mediated community coordination.

This public repository is being prepared for a future source release. The current repository state is intentionally scaffold-only while pre-release cleanup, documentation, licensing, and security review are completed.

## Current status

Public repository space created.

Source code is not published yet.

## Project direction

ARGUS is designed around:

- structured operational records
- dispatcher-mediated workflows
- responder coordination
- privacy-conscious defaults
- Matrix / | base | communications integration
- self-hostable community infrastructure
